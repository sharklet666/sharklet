# 煤球（A级 · 第一召唤物 · 全书第一个开智样本）

## 维度1 · 基本身份
- F级变异灰史莱姆，林默用新手礼包召唤券抽到的"垃圾签"（别人眼中的下下签）。
- 林默的进化视界里，它头顶浮着一条从未见过的隐藏进化链：**吞噬系 → ？（混沌方向）**。
- 记忆锚点：①进食时全身咕噜咕噜冒泡；②装死时摊成一张完美的饼。

## 开智阶段表（随进化逐级解锁，写作时严格按阶段给能力，不许提前）

| 阶段 | 解锁节点（占位，随细纲定章） | 能做什么 |
|---|---|---|
| 0 本能期 | 卷一开局 | 吃、打、装死、黏着林默；只认攻击/撤退/停留等基础指令，**没有情绪、没有交流** |
| 1 情绪期 | 第一次进化后 | 有喜怒委屈：会吃醋、会耍赖求投喂、被骂会缩水 |
| 2 交流期 | 第二次进化后 | 拟声+形体表达成体系，听得懂复杂话，会用变形**演示**情报 |
| 3 人格期 | 高阶进化后 | 完整人格、独立意志，可脱离基础指令自主决策、独自带队 |

> 开篇它就是个"蠢得令人发指"的本能生物。林默对它也只能下基础指令——他强在把本能单位用运营玩出花，不是靠召唤物通灵。

## 维度2 · 核心性格（本能期可见部分 + 开智后的定型方向）
- **本能核心驱动**：干饭，以及黏着林默（认主本能，来源成谜，后期与混沌系血脉一起回收）。
- **开智后定型**：吃货市侩 + 认怂极快 + 护主不要命；越成长越像个又怂又讲义气的损友。
- **冲突第一反应**：装死，或缩到林默脚后跟。

## 维度3 · 灵魂场（前3条是本能期就有的本能铁律，第4条起随开智显现）
1. 有吃的先干饭，干完再干活。
2. 危险来临立刻装死，绝不硬撑。
3. **护主本能**：谁敢碰林默，跟谁拼命——它唯一打破"装死"原则的情形。本能期就有，林默最初以为是程序设定，后期才明白是认主。
4. 〔情绪期〕会争宠：林默契约新召唤物，它当众摆脸子。
5. 〔人格期〕林默的命令它可以违抗——但只在"去送死"这一件事上违抗。

## 维度4 · 语言指纹（分阶段解锁，无人类语言）
- 阶段0：只有无差别的"咕噜"和身体反应，林默靠观察猜它状态。
- 阶段1起：咕噜＝开心/进食中；啵＝应答；嘶＝警戒；无声缩小＝委屈。
- 情绪用体型表达：开心冒泡 / 愤怒胀大 / 委屈缩水。
- 阶段2起：用身体变形**演示**（变成它见过的怪物形状给林默看）。

**蒙名测试**：出场不是在吃就是在装死、只会"咕噜""啵"的，就是煤球。

## 维度5 · 关系与成长弧
- 与林默：第一个无条件黏着他的存在。林默护它，它本能护林默；开智后双向奔赴不点破。
- 成长弧：F级灰史莱姆 → 隐藏吞噬链逐级进化+逐级开智（每级形态、习性、口癖微妙变化，逐卷登记）→ 未来军团的"老兵"与精神图腾。
- 与后续主力召唤物：开智后的"老大哥"，负责带坏新来的（喜剧生态位：内卷/吃瓜的发起者）。
- 功能定位：萌点+喜剧源+全书最长伏笔（混沌系进化链+认主本能的来源）的载体。**它当角色写，不当工具写**（对标：十一+虫虫的合体位置）。

## 写作提示
- 它的喜剧感来自"吃货+怂+护主"三件套的自我反差，不靠旁白说"它很搞笑"。
- 本能期写蠢要具体：听不懂"绕后"、追着掉落物跑偏、林默说撤退它正好吃撑了动不了——蠢事要制造战术麻烦，而不只是卖萌。
- 每次进化后的第一次登场，给一个完整锚点场景：**新形态+新解锁的智能+旧习惯不变**（进化了照样先干饭）。
