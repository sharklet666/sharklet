# 《混沌之争》World Bible

> 本文件是全书规则的最高依据。任何章节与本文件冲突时，改章节，不改规则。
> 目标体量：2000字/章 × 约500章。

## 0. 一句话核心

外星文明将游戏《混沌之争》投放蓝星"培养战士"以对抗混沌族；穿越而来的前职业电竞选手林默，觉醒出被全服误判为"废品"的神级召唤天赋，一路登顶——而游戏，只是开始。第100天，游戏入侵现实。

## 1. 核心冲突源（一切设定服务于此）

**秩序 vs 混沌。**

- 游戏 = 秩序力量的规则化：把超凡力量翻译成等级、技能、面板、规则。

- 混沌族 = 反规则的存在：吞噬规则本身，让"等级""技能""物理定律"失效。

- 外星文明（后称**播种者**）投放游戏的真实动机是全书最大长线钩。

  - 表面说法：培养援军，对抗混沌族。

  - 真相方向（后期揭示，行文只露马脚不点破）：蓝星是试验场/筛选场，游戏是收割工具。

  - 林默的穿越与此同源：他的原世界，疑似上一批试验场。

## 2. 物理规则层（超凡机制）

### 2.1 游戏降临与登录

- 某日，全蓝星16岁以上人类同时获得《混沌之争》登录资格。

- 意识沉浸式登录：任何地点闭眼冥想即可进入，身体进入浅睡眠状态，随时可被现实唤醒。

- 游戏时间与现实 1:1。

### 2.2 觉醒机制（公开性 = 误解引擎）

- 首次登录即在新手村广场进行觉醒仪式：**职业 × 品级**同时判定。

- 觉醒光柱全广场可见，系统公告同步播报——**天赋信息公开透明**，这是"林默被当成废品"的逻辑根。

- 光柱色谱：F灰白 / E白 / D绿 / C蓝 / B紫 / A橙 / S金 / SS赤金 / SSS七彩。

- 林默：觉醒时面板显示职业为召唤师，天赋等级显示【未知】。全场从未见过，一致认定林默是"连F级都不如的废物"。

### 2.3 职业与品级（术语全书统一）

- **职业**（6种）：战士 / 法师 / 射手 / 刺客 / 牧师 / 召唤师。

- **品级**（9档）：F / E / D / C / B / A / S / SS / SSS。

- 对外宣称SSS封顶。**隐藏第10档「神级」不公开**——系统无法识别，故显示【未知】。

- 行文中"天赋"一词仅作统称，避免与"品级"混用。

### 2.4 等级段位（每10级一段，全书统一）

| ----- | -- | ------ | -- |
| 1-10  | 黑铁 | 51-60  | 钻石 |
| 11-20 | 青铜 | 61-70  | 星耀 |

### 2.5 召唤师机制（"最弱职业"的结构性原因）

**蓝条**：大部分职业施法耗蓝，召唤师受蓝条钳制最深——召唤本身耗蓝，召唤物释放技能的蓝也由御主支付。

1. **召唤位锁死**：同时在场的召唤物数量由品级决定：F=1、E=2、D=3、C=4、B=5、A=7、S=9、SS=12、SSS=15。
2. **召唤耗蓝**：每召唤一只一次性扣除大量法力；召唤物被收回后重新召唤，要再次付费。
3. **技能耗蓝**：召唤物使用技能，法力统一走御主的蓝条。
4. **召唤物默认只有原始的进攻意识和基本的进攻指令**：能感知敌人、自动普通攻击，能听懂攻击/撤退/停留等少数基础指令；不会走位、不会配合、不会执行复杂战术。
5. 召唤物前期个体战力远低于同级玩家，且各自独立吃经验、装备、进化材料。
6. **开智规则（例外通道）**：普通召唤物终生停在本能层；**变异体 / 拥有隐藏进化链的个体，随每次进化逐级开智**：
   - 本能期：吃、打、装死、认主，只认基础指令；
   - 情绪期：有喜怒委屈，会吃醋会耍赖；
   - 交流期：能用拟声、动作、变形简单表达，听得懂复杂话；
   - 人格期：完整人格、独立意志，可自主决策。
   - 开智个体＝主力队（建卡），本能单位＝军团编制（见§6）。煤球是全书第一个开智样本，其开智过程是长线爽点（对标虫虫进化）。

→ 结论：**蓝条决定下限，召唤位决定上限**——蓝浅、位少、召唤物又蠢，召唤师因此被公认为最弱职业。
→ 但召唤物只认基础指令，强弱全看御主的编队、集火、拉怪和运营：这正是 RTS 职业选手林默的老本行。

### 2.6 林默的天赋「万灵之主」（神级，仅对己显示）

1. **无限军势**：召唤位不受品级限制，随自身等级每升1级翻3倍——Lv1=1、Lv2=3、Lv3=9、Lv4=27……等级即兵力，后期可一人成军。
2. **极速回蓝**：法力恢复速度为同级玩家的数十倍，并随等级成长。
3. **进化视界**：可见每只召唤物的**隐藏进化链**及解锁条件。
4. 【后期底牌，早期不写死】可契约混沌族——逻辑根：混沌族也是"生灵"，只是反规则。

### 2.7 死亡与惩罚

- 游戏期：死亡 = 等级-5 + 24小时虚弱。

- 现实篇（入侵后）：死亡 = 真死。

## 3. 社会规则层

### 3.1 游戏期（第1天—第100天）

- 品级决定起点，等级决定地位；实力榜成为新货币。

- 公会、战队、资本、国家队背景组织陆续入场。

- 游戏身份与现实身份**不强制绑定**（匿名性 = 林默"神秘人"打脸循环的保护壳）。

### 3.2 现实篇（第100天起，游戏入侵现实）

- 游戏规则覆盖现实物理：**混沌能量场免疫常规热武器**，只有游戏力量可伤混沌族。

- 城市安全区化，现实出现副本与混沌裂隙；军队全面玩家化。

- 游戏中的等级、装备、技能全部具现。

## 4. 约束规则层（禁区与代价，严格执行）

1. **极速回蓝 ≠ 无限蓝**：林默前期蓝量上限低，海量召唤+技能齐射可能一波抽空；蓝空时无法召唤，召唤物也放不出技能。
2. 隐藏进化链的解锁需要稀有材料+特定条件，链越强条件越苛刻。
3. 保命道具（复活币等）极度稀缺，主角也不例外。
4. 金手指的所有限制全书有效，不为剧情开后门；若剧情与规则冲突，改剧情。

## 8. 术语速查

- 职业 ≠ 品级；段位 = 等级区间；光柱颜色 = 品级公示。

- 装备/技能书品级与天赋品级同色谱（F白装……SSS七彩装）。

- "面板""系统公告""排行榜"为游戏内信息公开三件套，凡需制造公开误解，优先用这三样。

## 9. 文风与爽点规范（对标《不科学御兽》，全书执行）

### 9.1 爽点单元（四步循环，每个爽点章节必须跑通）
1. **规则套利**：林默发现一条被所有人忽略的游戏规则（仇恨机制、地形、蓝量回复、召唤物编队）。
2. **低成本验证**：用电竞常识试出来，不靠运气、不靠天降。
3. **数据结算**：用精确数字给反馈——首杀耗时、兵力（1→3→9→27）、蓝条剩余、伤害数值。成长必须"看得见进度条"。
4. **围观震惊 + 面瘫收尾**：震惊交给高旭/排行榜/全服公告；林默不辩解不自证，金句收尾（"这波不亏""先复盘"）。

### 9.2 节奏
- 每3-5章高强度推进后，插1章纯日常（喂食、煤球犯蠢、训练吐槽）——爽点与笑料交替投喂。
- 每30-50章一个小弧，每卷开篇给一个**具体且有截止时间**的困境。
- 温度主基调2档，打脸/团战3-4档；本作有生存+末世底色，不为学轻松消解危机感。
- 2000字短章：每章至少一个微钩，**章尾钩必须**，信息钩/危机钩/情感钩轮换。

### 9.3 语言
- 两层语言混用：①电竞黑话×面板语（集火、仇恨、Timing、阵容、滚雪球、运营）；②玩家口语梗（GG、下饭、战五渣、非酋）。
- 错位类比公式：陌生超凡物＝读者熟悉的日常物，类比里带吐槽（如蓝条＝工资池，召唤物放技能＝刷公司电费）。
- 短句短段为主；心理只写决策过程和身体反应，不抒情；数字和计时精确化。
- 章名走电竞梗双关，且字面扣本章剧情（如"首杀，就这？""一个师的兵力"）。

### 9.4 喜剧分工（固定班底）
- 林默：冷面数据腔，负责反差和金句，不负责搞笑表演。
- 煤球：身体喜剧（干饭、装死、摊饼），开智前蠢得令人发指本身就是笑点。
- 高旭：读者嘴替，负责提问、震惊、复读"不可能"、当场真香。

### 9.5 每章自检三问
- 这章的"规则套利"是什么？
- 数据跳了没有？
- 最后谁替读者喊出了那句震惊？
